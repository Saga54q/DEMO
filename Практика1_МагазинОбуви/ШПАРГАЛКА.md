## Фаза 2. Таблицы (~15 мин)

Для каждой таблицы: **Создать → Конструктор таблиц** → поля и типы → ПК → Ctrl+S (имя таблицы).

| Таблица | Поля (тип) |
|---|---|
| Клиенты | ID_Клиента (Счётчик, ПК), ФИО (Короткий текст 100), Логин (Короткий текст 50), Телефон (Короткий текст 20) |
| Категории | ID_Категории (Счётчик, ПК), Наименование (Короткий текст 50) |
| Производители | ID_Производителя (Счётчик, ПК), Наименование (Короткий текст 50), Страна (Короткий текст 50) |
| Модели | ID_Модели (Счётчик, ПК), Наименование (Короткий текст 100), ID_Категории (Числовой, Длинное целое), ID_Производителя (Числовой, Длинное целое), Состав (Короткий текст 100), Описание (Длинный текст), Цена (Денежный), Изображение (Вложение) |
| ТоварныеПозиции | ID_Позиции (Счётчик, ПК), ID_Модели (Числовой, Длинное целое), Размер (Числовой, Байт), Количество (Числовой, Длинное целое) |
| Заказы | ID_Заказа (Счётчик, ПК), ID_Клиента (Числовой, Длинное целое), ДатаЗаказа (Дата/время) |
| СоставЗаказа | ID_Строки (Счётчик, ПК), ID_Заказа (Числовой, Длинное целое), ID_Позиции (Числовой, Длинное целое), Количество (Числовой, Длинное целое), ЦенаЗаЕдиницу (Денежный) |

- [ ] Все ВК — «Числовой → Длинное целое» (под тип Счётчика!).
- [ ] Свойства: Цена и ЦенаЗаЕдиницу → правило `>=0`; Количество → правило `>=0`.
- [ ] Именование единое: ID_Сущность везде одинаково, без пробелов в именах.

## Фаза 3. Данные (~8 мин)

- [ ] Порядок импорта: Клиенты → Категории → Производители → Модели → ТоварныеПозиции → Заказы → СоставЗаказа.
- [ ] В `Модели.xlsx` нет столбца Изображение — в мастере выбери «Не импортировать поле».
- [ ] Проверил: в каждой таблице правильное число записей (5, 4, 4, 6, 15, 5, 9).

## Фаза 4. Связи (~7 мин)

**Работа с базами данных → Связи → Показать таблицу** (добавить все 7) → перетащить ПК → ВК → «Обеспечение целостности данных».

| Родитель → Родительский ключ | Дочерняя → Внешний ключ | Каскадное удаление |
|---|---|---|
| Клиенты.ID_Клиента | Заказы.ID_Клиента | НЕТ (клиентов с заказами не удаляем) |
| Заказы.ID_Заказа | СоставЗаказа.ID_Заказа | ДА (удалил заказ — удалились строки) |
| ТоварныеПозиции.ID_Позиции | СоставЗаказа.ID_Позиции | НЕТ |
| Модели.ID_Модели | ТоварныеПозиции.ID_Модели | НЕТ |
| Категории.ID_Категории | Модели.ID_Категории | НЕТ |
| Производители.ID_Производителя | Модели.ID_Производителя | НЕТ |

- [ ] У каждой связи отмечено «Обеспечение целостности данных».
- [ ] Сохранил макет окна связей (Ctrl+S).

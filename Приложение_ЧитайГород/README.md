# «ЧитайГород» — приложение к ДЭ 09.02.07

Рабочая учебная система по реальному варианту **В1_КОД 09.02.07-2-2026-БУ**. Приложение написано на Python/Tkinter, база — SQLite. При первом запуске данные берутся из исходных Excel-файлов в `import/`.

## Запуск в PyCharm

1. Открой эту папку как отдельный проект.
2. В терминале PyCharm выполни `pip install -r requirements.txt`.
3. Запусти `main.py`. При первом запуске создадутся `chitai_gorod.db` и папка `images/` с фотографиями.
4. Для обычного запуска повторно нужны только `main.py`, `database.py`, `chitai_gorod.db`, `images/` и папка `import/` с картинками-ресурсами.

Нужен Python 3.9+ с Tkinter. Для показа и обработки JPG-фотографий используется Pillow; Excel-файлы при первом запуске читает openpyxl.

## Что реализовано

- вход по данным из Excel, гостевой просмотр и выход на окно входа;
- разные возможности гостя, клиента, менеджера и администратора;
- список из 20 реальных товаров с изображением, категорией, описанием, производителем, поставщиком, ценой, единицей, остатком и скидкой;
- цена со скидкой рассчитывается как `цена × (100 − скидка) / 100`;
- скидка больше 25% выделяется бирюзовым, отсутствие остатка — серым; в карточке товара исходная цена перечёркнута красным, итоговая показана рядом;
- у менеджера и администратора поиск по всем текстовым характеристикам, сортировка по цене/остатку и фильтр скидки; изменения применяются сразу и совместно;
- только администратор добавляет, изменяет и удаляет товары; окно формы блокируется от повторного открытия;
- цена, скидка и остаток проверяются; фото автоматически вписывается в 300 × 200 px и сохраняется в `images/`, в базе хранится относительный путь; старое фото удаляется при замене, если оно больше не используется;
- менеджер и администратор просматривают заказы; администратор добавляет, изменяет и удаляет заказ;
- продукт, который уже указан в заказе, удалить нельзя (ограничение внешнего ключа).

## Структура

- `main.py` — интерфейс и правила доступа (читается как последовательность экранов);
- `schema.sql` — SQL-скрипт создания таблиц, PK/FK и ограничений;
- `database.py` — запросы к SQLite и операции чтения/изменения;
- `import_data.py` — первичная загрузка исходных Excel-листов;
- `import/` — выданные Excel-таблицы, логотип, иконка, исходные фото и заглушка;
- `images/` — активные фотографии, путь к которым хранится в Product.image;
- `ER_диаграмма.pdf` — таблицы, атрибуты, PK/FK и связи;
- `Блок-схема.pdf` — алгоритм приложения;
- `ШПАРГАЛКА.md` — пошаговое объяснение выполнения задания и проверок.

## Проверки и отчёт

Запустить проверки базы без GUI: `python -m unittest -v`.

`Отчёт_скриншоты_ШАБЛОН.docx` — шаблон отчёта по реальному прогону. Вставь в него свои снимки работающего приложения в PyCharm/Windows вместо серых полей; макеты не выдаются за скриншоты.

## Контрольный запуск

Администратор `1/1` → поиск слова `Linux` → сортировка «Цена ↑» → фильтр «13–16,99%» → добавить тестовый товар с нулевым остатком → проверить серую строку → изменить скидку на 30% и увидеть бирюзовую строку → попробовать удалить товар, который уже есть в заказе (система запретит).

# «ВелосипедДрайв» — Вариант 2, ДЭ 09.02.07-2-2026-БУ

Отдельное приложение для **Варианта 2** (магазин велосипедов), созданное по его собственным Excel-файлам и требованиям. Python/Tkinter + SQLite. Не подменяет Вариант 1 «ЧитайГород».

## Запуск в PyCharm

1. Открой эту папку как отдельный проект.
2. В терминале PyCharm выполни `pip install -r requirements.txt`.
3. Запусти `main.py`. Создадутся `velodrive.db` и фотографии в `images/`.
4. Для тестов базы: `python -m unittest -v`.

Нужен Python 3.9+ с Tkinter. Pillow обрабатывает JPG-фотографии, openpyxl читает исходные Excel-файлы при первом запуске.

## Реализовано по Варианту 2

- 10 велосипедов из предоставленного Excel, 10 заказов, 20 строк состава;
- вход, гостевой режим, роли и выход обратно на вход;
- фото/заглушка, категория, описание, производитель, поставщик, цена, скидка, единица измерения и складской остаток;
- скидка **строго больше 15%** — фон `#483D8B`; товара нет — серый фон; исходная цена при скидке перечёркнута красным, рядом показывается итоговая цена чёрным;
- менеджер/администратор: живой поиск по всем текстовым полям, комбинируемые фильтры скидки и сортировка по цене, остатку и скидке;
- фильтры Варианта 2: `Все диапазоны`, `0–11,99%`, `12–18,99%`, `19% и более`;
- администратор: CRUD товаров и заказов, проверка цены/скидки/остатка, одно окно редактирования, сохранение фото 300 × 200 px и относительного пути; нельзя удалить велосипед из заказа;
- фирменный стиль: Arial, белый фон, `#6A5ACD`, акцент `#4B0082`, ресурсы Варианта 2.

## Файлы

- `main.py` — окна и управление доступом;
- `database.py` + `schema.sql` — SQLite-запросы, PK/FK, ограничения;
- `import_data.py` — импорт и очистка исходных данных Excel;
- `import/` — исходные книги, фото, иконка, логотип и заглушка;
- `docs/` — задание Варианта 2, описание предметной области и руководство по стилю;
- `ER_диаграмма.pdf`, `Блок-схема.pdf` — материалы Варианта 2;
- `ШПАРГАЛКА.md` — пошаговый разбор проектирования и импорта;
- `Отчёт_скриншоты_ШАБЛОН.docx` — шаблон для настоящих скриншотов после запуска на Windows.

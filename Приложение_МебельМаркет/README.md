# МебельМаркет — вариант № 5 (тема: мебель)

Учебное настольное приложение для учёта мебели и остатков на нескольких складах. Основной интерфейс сейчас использует Python 3.9+, Tkinter и SQLite; `create_access_db.py` отдельно создаёт Access `.accdb`, но GUI пока к нему не подключён. Порядок запуска Access-генератора — в `README_ACCESS.md`.

## Важно об исходных материалах

В репозиторий включены четыре фотографии страниц задания, приложенные пользователем. На них указаны роли, перечень полей товара, складская тематика, ER-диаграмма, импорт, цвета и операции с заказами. **Исходные приложения 1–3 (Excel-файлы с данными, ресурсы и точное руководство по стилю) среди фотографий отсутствуют.** Поэтому `import/Furniture_demo_import.xlsx` — явно обозначенный демонстрационный набор, созданный для проверки приложения, а не оригинальные данные экзамена. Для точного соответствия пришлите полные приложения задания; заменить демонстрационный Excel можно без изменения интерфейса.

Компания названа «МебельМаркет» только для учебного интерфейса. Указанный в задании цвет `#008080` применён к строке скидки строго выше 15%; товары с нулевым суммарным остатком отображаются серым. Остальная цветовая палитра — нейтральная, так как руководство по стилю (Приложение 3) не приложено.

## Быстрый запуск в Windows / PyCharm

1. Откройте эту папку как проект в PyCharm.
2. В терминале PyCharm из корня проекта выполните:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

   Если PyCharm уже создал `.venv`, первую команду пропустите.
3. Запустите `main.py` кнопкой **Run** или выполните:

   ```powershell
   .\.venv\Scripts\python.exe main.py
   ```

4. Для проверок выполните:

   ```powershell
   .\.venv\Scripts\python.exe -m unittest -v
   ```

При первом запуске схема создаётся из `schema.sql`, демонстрационные строки импортируются из Excel, база `mebelmarket.db` создаётся рядом с программой.

## Возможности по страницам задания

- окно входа первым открывается при запуске; доступ гостя и проверка логина/пароля из SQLite;
- после входа в шапке показываются ФИО и роль; выход возвращает к окну входа;
- гость и авторизованный клиент видят каталог без поиска, фильтров и сортировки;
- менеджер видит каталог с поиском, фильтром по категории/скидке и сортировкой, а также список заказов;
- администратор имеет те же возможности плюс CRUD товаров и заказов;
- каталог выводит фото (для отсутствующего изображения — `import/picture.png`), название, категорию, описание, производителя, поставщика, цену, единицу, скидку и суммарный складской остаток;
- остатки нормализованы в таблице `Inventory` по отдельным складам; в карточке товара показываются суммы и остатки по каждому складу;
- скидка **строго больше 15%** выделяется фоном `#008080`; при нулевом суммарном остатке применяется серый фон;
- при скидке исходная цена перечёркнута красным, итоговая цена указана чёрным;
- удаление товара, используемого в заказе, блокируется внешним ключом.

Фильтр скидки и сорта в интерфейсе — практическая реализация общего требования «фильтрация/сортировка»; конкретные диапазоны на предоставленных фото задания не указаны.

## Структура проекта

- `main.py` — окна входа, каталог, карточка, формы товара и заказа;
- `database.py`, `schema.sql` — схема SQLite, запросы, CRUD и ограничения;
- `import_data.py` — импорт из Excel и проверка ссылок;
- `import/Furniture_demo_import.xlsx` — учебные импорт-данные;
- `tools/create_demo_workbook.py` — повторное создание демонстрационной книги;
- `tools/create_assets.py` — логотип, иконка и заглушка изображения;
- `tools/create_diagrams.py`, `tools/create_report_template.py` — пересоздание PDF/DOCX (пакеты для этого указаны в `requirements-docs.txt`);
- `Модуль_создания_БД.bas` — модуль VBA для создания таблиц/связей прямо в открытой базе Access;
- `create_access_db.py`, `README_ACCESS.md` — альтернативный Windows-генератор Access через COM/ODBC и инструкция;
- `mebelmarket.db` — готовая учебная база с импортированными данными;
- `ER_диаграмма.pdf`, `Блок-схема.pdf` — диаграмма сущностей и блок-схема приложения;
- `Отчёт_скриншоты_ШАБЛОН.docx` — шаблон отчёта; поля снимков нужно заменить скриншотами реального запуска;
- `ШПАРГАЛКА.md` — порядок выполнения модулей и краткое объяснение структуры;
- `docs/source_photos/` — исходные фотографии условия от пользователя.

## Проверяемый сценарий

1. Войти как гость: убедиться, что каталог виден, а фильтры скрыты.
2. Войти менеджером: искать «Лофт», выбрать категорию «Диваны», сортировать по остатку и открыть заказы.
3. Убедиться, что скидка 20% подсвечена бирюзовым, а товар с нулевым остатком серый.
4. Войти администратором: добавить тестовый стол с остатком на выбранном складе, изменить его, затем удалить.
5. Попробовать удалить товар из заказа: база должна отказать.
6. Добавить/изменить/удалить тестовый заказ.

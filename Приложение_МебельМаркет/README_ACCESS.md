# Создание мебельной БД средствами Access/VBA

В архиве есть модуль `Модуль_создания_БД.bas`. Он создаёт таблицы, первичные ключи, уникальные индексы, правила полей и связи с обеспечением ссылочной целостности. Отдельно лежит `create_access_db.py` — альтернативный Windows-генератор через COM/ODBC.

## Запуск модуля VBA внутри Access

1. Откройте Microsoft Access и создайте пустую базу: **Файл → Создать → Пустая база данных**. Сохраните её как `МебельМаркет.accdb`.
2. Нажмите **Alt+F11**.
3. В VBA-редакторе проверьте **Tools / Сервис → References / Ссылки**: должна быть доступна библиотека **Microsoft Office xx.0 Access database engine Object Library** (DAO).
4. Если хотите вставить код вручную: **Insert / Вставка → Module / Модуль**, вставьте код из `Модуль_создания_БД.bas` без первой строки `Attribute VB_Name = ...`.
   Либо импортируйте BAS-модуль через **File → Import File**.
5. Поставьте курсор внутри `BuildFurnitureDatabase` и нажмите **F5**.
6. Вернитесь в Access. Таблицы появятся в области навигации; связи проверьте через **Работа с базами данных → Схема данных**.

Повторный запуск не удаляет таблицы и данные: существующие таблицы, индексы и связи пропускаются; недостающие создаются. Модуль строит схему, но **не загружает строки из Excel**. После схемы импортируйте исходные Excel-файлы через **Внешние данные → Новый источник данных → Из файла → Excel** и переносите записи в нормализованные таблицы. На присланных фото исходные Excel-приложения отсутствуют.

## Важно

Модуль VBA работает в уже открытой пустой `.accdb`: он создаёт в ней структуру, а не новый файл базы на диске. Это обычное ограничение — чтобы выполнить модуль, Access сначала должен открыть файл, где этот модуль хранится.

Текущий `main.py` приложения всё ещё подключён к SQLite. Созданная VBA-схема Access пока не подключена к интерфейсу Python. Для этого отдельно нужно переписать функции `database.py` на Access/ODBC и проверить их на Windows с Access.

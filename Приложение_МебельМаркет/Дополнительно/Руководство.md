# МебельМаркет — запуск и структура поставки

> Учебный проект по фотографиям основных условий демонстрационного экзамена 2026 (они сохранены в `Фото_условия/`). Отдельные приложения с исходными данными/ресурсами и полный style guide не приложены, поэтому тестовые записи и нейтральный макет условные. Отдельный пункт 7 в запросе на подготовку комплекта отсутствовал.

## Коротко о проекте

- Microsoft Access — локальная база данных `.accdb` и нативный стандартный модуль DAO/VBA.
- Python — интерфейс магазина на Tkinter и ODBC-доступ к Access.
- При старте открывается окно входа с отдельным переходом к гостевому просмотру.
- Гость и клиент видят каталог без поиска/фильтрации/сортировки; менеджер и администратор получают поиск и сортировку.
- Карточка товара содержит фото или заглушку, категорию, наименование, описание, производителя, поставщика, цену, единицу измерения, остатки по складам и скидку. Скидка выше 15% подсвечивается `#008080`; отсутствующий товар — серым; прежняя цена перечёркнута красным.
- Менеджер просматривает товары и заказы; администратор может добавлять, изменять и удалять товары и заказы. Дополнительно реализован клиентский сценарий корзины/оформления заказа.
- Роли: гость, авторизованный клиент, менеджер, администратор. Для демонстрации импортируются готовые учётные записи.
- Файл `.accdb` не включён в поставку: его нужно создать в Microsoft Access и выполнить модуль.

## Подготовка Access

1. На Windows установите Microsoft Access и Access Database Engine/ODBC той же разрядности, что и установленный Python.
2. Создайте пустую базу `БД/МебельМаркет.accdb`.
3. Нажмите `Alt+F11` → редактор VBA → **Файл → Импорт файла…** → выберите `Модуль_создания_БД.bas`.
4. Вернитесь в редактор Access, нажмите `Alt+F8`, выберите `BuildFurnitureDatabase`, нажмите **Выполнить**. Должны появиться 11 таблиц, 4 сохранённых запроса и связи.
5. Если Access блокирует код, разрешите запуск VBA только для своей локальной копии/доверенного расположения. Не отключайте защиту глобально.

> Модуль использует DAO, встроенный в Access. Он добавляет отсутствующие объекты, но не мигрирует существующие таблицы. Запускайте его в новой пустой базе; при ошибке сохраните её текст и исправьте объект/схему до импорта.

## Импорт условных данных

Сначала создайте базу и запустите VBA. Затем в терминале из папки `Приложение/` выполните:

```powershell
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py ..\БД\СоздатьДемоДанные.py
py ЗаполнитьБД.py
```

`ЗаполнитьБД.py` отказывается импортировать данные, если в таблице `Товары` уже есть записи. Это защита от случайной перезаписи. Создайте пустую БД, если хотите повторить демонстрационный импорт.

Условные пользователи после импорта:

| Роль | Логин | Пароль |
|---|---|---|
| Клиент | `client@mebel.local` | `Client2026` |
| Менеджер | `manager@mebel.local` | `Manager2026` |
| Администратор | `admin@mebel.local` | `Admin2026` |

Импортёр хранит пароли как SHA-256-дайджесты; приложение также принимает пароль из исходной таблицы в открытом виде и хеширует его при первом успешном входе (для совместимости с возможной таблицей из исходного приложения). Это учебный пример, а не промышленная аутентификация: для реального магазина нужны соль/медленный KDF, разграничение доступа, резервное копирование и серверная БД. Не используйте эти демо-пароли в других системах.

## Запуск Python-приложения

```powershell
cd Приложение
py -m pip install -r requirements.txt
py main.py
```

Путь к базе вычисляется относительно файлов приложения. Если окно не открывается, проверьте: Windows, установленный Access ODBC-драйвер, совпадение 32/64-битной разрядности Python и драйвера, наличие базы и выполнение VBA. Пакет `tkinter` должен входить в выбранную сборку Python.

## Ограничения проверки

Код Python проверен на синтаксис, Excel-файл создан скриптом. Среда подготовки не содержит Windows, Microsoft Access, Access ODBC-драйвера и полноценного Tk GUI. Поэтому нельзя заявлять, что `.accdb`, VBA-модуль и весь сценарий запуска прошли проверку в Access/Windows. Перед сдачей выполните эти шаги на целевом компьютере и зафиксируйте реальные результаты.

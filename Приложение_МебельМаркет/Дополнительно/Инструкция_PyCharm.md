# Запуск проекта в PyCharm

1. Откройте PyCharm → **Open** → выберите папку `Приложение_МебельМаркет/Приложение` (либо откройте всю папку проекта, но выберите `Приложение` как рабочую директорию запуска).
2. Если предложено, создайте виртуальное окружение **New Virtualenv** на Python 3.10+.
3. Откройте встроенный Terminal и установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

4. Создайте `.accdb` и выполните VBA-модуль согласно `Руководство.md`. Проверьте путь `Приложение_МебельМаркет/БД/МебельМаркет.accdb`.
5. Перейдите в `БД/` и запустите генератор условного Excel-набора:

```powershell
python СоздатьДемоДанные.py
```

6. В PyCharm: **Run → Edit Configurations…** → **+ → Python**. Укажите:
   - Script path: `Приложение/ЗаполнитьБД.py`;
   - Working directory: `Приложение/`;
   - Interpreter: созданное виртуальное окружение.
7. Нажмите **Run**. После успешного импорта смените Script path на `Приложение/main.py` и снова нажмите **Run**.
8. Для отладки задайте breakpoint, например в `_place_order`, затем используйте **Debug**.

Путь к базе не зависит от Working directory, а строится относительно `main.py`. Запускать импорт следует только один раз в пустую базу. Если ODBC-драйвер не находится, установите Microsoft Access Database Engine той же разрядности, что и Python, и перезапустите PyCharm.

# База данных Access

1. В Microsoft Access создайте пустой файл `МебельМаркет.accdb` в этой папке.
2. Импортируйте `Модуль_создания_БД.bas` через `Alt+F11` → **Файл → Импорт файла…**.
3. Запустите `BuildFurnitureDatabase` из `Alt+F8`.
4. Для условного наполнения запустите `СоздатьДемоДанные.py`, затем `Приложение/ЗаполнитьБД.py`.

Файл `.accdb` локальный и исключён из Git/ZIP. VBA-модуль предназначен для новой пустой базы, не является мигратором.
